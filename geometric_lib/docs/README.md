## Установка
Библиотека не находится в PyPl. Склонируйте репозиторий для запуска функций:
```
git clone https://github.com/kazuhato/geometric_lib.git
cd geometric_lib
```


## Модули

| Файл | Фигура |
| :--- | :--- |
| `circle.py` | круг |

| `square.py` | квадрат |

### Формулы
| Фигура | Площадь | Периметр |
| :--- | :--- | :--- |
| Круг | S = πR² | P = 2πR |
| Прямоугольник | S = a · b | P = (a + b) · 2 |
| Квадрат | S = a² | P = 4a |
| Треугольник | S = a · h / 2 | P = a + b + c |



## Описание функций

## circle.py

`area(r)`  
Вычисляет площадь круга по формуле S = πR².

**Возвращает:** площадь круга.

| Параметр | Описание |
| :--- | :--- |
| `r` | радиус круга |

**Пример вызова:**

```python
s = area(3)
print(s)  # 28.26
```
`perimeter(r)`  
Вычисляет длину окружности по формуле P = 2πR.

**Возвращает:** длину окружности.
| Параметр | Описание |
| :--- | :--- |
| `r` | радиус круга |


**Пример вызова:**

```python
r = perimeter(3)
print(r)  # 18.84
```

## rectangle.py

`area(a)`  
Вычисляет площадь прямоугольника по формуле S = a · b.

**Возвращает:** площадь прямоугольника.

| Параметр | Описание |
| :--- | :--- |
| `a` | длина первой стороны прямоугольника |
| `b` | длина второй стороны прямоугольника |

**Пример вызова:**

```python
s = area(2, 3)
print(s)  # 6.0
```
`perimeter(a, b)`  
Вычисляет периметр прямоугольника по формуле P = (a + b) · 2.

**Возвращает:** периметр прямоугольника.
| Параметр | Описание |
| :--- | :--- |
| `a` | длина первой стороны |
| `b` | длина второй стороны |

**Пример вызова:**

```python
a = perimeter(2, 5)
print(a)  # 14.0
```

## triangle.py


`area(a, h)`

Вычисляет площадь треугольника по формуле S = a · h / 2.

**Возвращает:** площадь треугольника.

| Параметр | Описание |
| :--- | :--- |
| `a` | длина основания |
| `h` | высота, опущенная на основание |

**Пример вызова:**

```python
a = area(2, 4)
print(a)  # 4.0   
```  

`perimeter(a, b, c)`  
Вычисляет периметр треугольника по формуле P = a + b + c.

**Возвращает:** периметр треугольника.
| Параметр | Описание |
| :--- | :--- |
| `a` | длина первой стороны |
| `b` | длина второй стороны |
| `c` | длина третьей стороны|

**Пример вызова:**

```python
a = perimeter(2, 4, 5)
print(a)  # 11.0
```
